                                     🏦👨‍💼 Restaurant Rating Project 🏦👨‍💼
                                     
This project is an end-to-end machine learning web application that analyzes Zomato restaurant data to predict prospective customer ratings based on business features. It builds and optimizes regression models using Scikit-Learn and deploys the highest-performing model via a live, interactive Flask web interface.

✨ Features:
- Real-time restaurant rating forecasting
- Automated missing data cleaning
- Multi-model regression algorithm analysis
- Interactive user-friendly input dashboard

🛠️ Technologies Used:
- Pandas
- NumPy
- Scikit-Learn
- Plotly
- Flask
- Pickle

🔍 Key Insights:
- Online orders significantly boost customer engagement distributions.
- Table reservations consistently ensure higher baseline ratings.
- Pricing and location directly dictate final scores.
- Large vote counts strongly correlate with excellent ratings.
